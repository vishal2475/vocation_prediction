# vocation_prediction

#  AI-Based Vacation Recommendation System

This project uses **machine learning** (Logistic Regression with TF-IDF) to predict the **sentiment** of vacation place feedback and recommends the best vacation spot based on:

-  Cost (less than or equal to ₹3000)
-  Rating (greater than or equal to 4.0)
-  Travel Time (less than or equal to 10 hours)
-  Positive feedback sentiment (predicted by AI)
